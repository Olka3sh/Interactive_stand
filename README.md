## О проекте

Программное ядро информационной системы управления производственным циклом изготовления интерактивных выставочных стендов. Система охватывает сквозной процесс от регистрации технического задания и производственного заказа до проверки складской обеспеченности комплектующими, контроля технологических операций и статистического анализа рекламаций отдела технического контроля (ОТК).

### Технологический стек
* **Языки программирования:** Python 3.13 (процедурная реализация алгоритмов), Java 21 LTS (объектно-ориентированная реализация ядра системы).
* **Моделирование и проектирование:** BPMN 2.0 (бизнес-процессы), ER-моделирование в нотации Crow's Foot (3НФ), блок-схемы алгоритмов (ГОСТ 19.701-90), UML 2.5 (диаграмма классов).
* **Проектируемая СУБД:** PostgreSQL 18.
* **Среда разработки и VCS:** IntelliJ IDEA 2025.3, Git / GitHub.

## Структура отчёта по практике

### Введение
Актуальность темы, объект и предмет исследования, цель работы и поэтапные задачи практики.

### 1. Предметная область
История развития интерактивных технологий в выставочной индустрии, текущее состояние рынка мультимедийных решений и обоснование необходимости автоматизации производственного учёта.

### 2. Описание бизнес-процесса
Декомпозиция процесса «Выполнение заказа на производство интерактивного стенда для выставки»: роли и зоны ответственности (менеджер проекта, конструктор, дизайнер, программист, сборщик, специалист ОТК), входы и выходы процесса, шаги выполнения, узкие места и потери.

### 3. Среда разработки и система контроля версий
Обоснование выбора среды разработки IntelliJ IDEA, языков Python 3.13 и Java 21, реляционной СУБД PostgreSQL 18 и системы контроля версий Git.

### 4. Аналитический этап (КТ2)
* **Модель бизнес-процесса в нотации BPMN 2.0:** дорожечная диаграмма технологического цикла с параллельными ветвями разработки и шлюзами маршрутизации брака.
* **Автоматизируемые операции:** обоснование автоматизации регистрации заказа, складского контроля дефицита и анализа брака ОТК.
* **Логическая модель данных:** реляционная ER-диаграмма в нотации Crow's Foot (7 сущностей в третьей нормальной форме).
* **Алгоритмическое обеспечение и процедурная реализация:** схемы и оценка вычислительной сложности алгоритмов ($O(C + N \cdot M)$ и $O(K)$), реализация на Python 3.13 без пользовательских классов.

### 5. Объектно-ориентированный этап (КТ3)
* **Диаграмма классов UML:** проектирование 13 классов и интерфейсов предметной области на основе логической модели данных.
* **Объектно-ориентированная реализация на Java 21:** инкапсуляция, наследование (`Defect` $\leftarrow$ `HardwareDefect`, `SoftwareDefect`), полиморфизм, паттерн «Стратегия» (`CostCalculationStrategy`) и параметризованные коллекции `List` и `Map`.
* **Сопоставление реализаций:** сравнительный анализ процедурного и объектно-ориентированного подходов по расширяемости, структуре кода, особенностям языков и идентичности результатов.

### 6. Организационный этап (КТ3)
* **Состав проектной команды:** распределение 5 проектных ролей, закреплённых артефактов и матрица компетенций для промышленного внедрения.
* **Анализ рынка труда и образовательные траектории:** исследование 10 профильных вакансий, анализ частотности требований, обзор образовательных программ и определение приоритетов профессионального роста.

### Список использованных источников
19 библиографических источников, оформленных в соответствии с ГОСТ Р 7.0.100-2018.

### Приложение А
Перевод фрагментов научного источника *Ibarra Kwick J. M. et al. Extended Reality Applications for CNC Machine Training: A Systematic Review (2024)*.
