## Структура отчёта

### Введение
Актуальность темы, объект и предмет исследования, цель работы и задачи по каждому этапу практики.

### 1. Предметная область
Краткая история развития интерактивных технологий в выставочной деятельности — от первых сенсорных киосков до современных мультимедийных инсталляций. Текущее состояние рынка и обоснование необходимости автоматизации производственного процесса.

### 2. Описание бизнес-процесса
Процесс «Выполнение заказа на производство интерактивного стенда»: участники и роли (менеджер проекта, конструктор, дизайнер, программист, сборщик/монтажник, специалист ОТК), вход и выход процесса, последовательность шагов, узкие места и потери.

### 3. Среда разработки и система контроля версий
Обоснование выбора инструментов: IntelliJ IDEA, Python 3.12, Java 21, PostgreSQL 18, Git.

### 4. Аналитический этап (КТ2)
* **Модель бизнес-процесса в нотации BPMN 2.0:** сквозная дорожечная диаграмма технологического цикла (6 ролей, события, параллельные ветвления и шлюзы типизации брака).
* **Автоматизируемые операции:** обоснование перевода рутинных шагов менеджера, конструктора и ОТК в программные функции (`check_materials_deficit`, `analyze_defect_statistics`).
* **Логическая модель данных:** реляционная ER-диаграмма в нотации Crow's Foot (7 сущностей: `Customer`, `Order`, `Employee`, `Component`, `Order_component`, `Operation`, `Defect`), разрешение связи M:N и обоснование нормализации до 3НФ.
* **Алгоритмическое обеспечение:**
    * *Алгоритм 1:* Проверка доступности комплектующих и расчёт себестоимости партии заказов. Сложность: время $O(C + N \cdot M)$, память $O(C + N \cdot M)$.
    * *Алгоритм 2:* Статистический анализ журнала рекламаций и расчёт показателей качества ОТК. Сложность: время $O(K)$, память $O(1)$.
* **Процедурная программная реализация:** консольный модуль на Python 3.12 без использования пользовательских классов (структуры данных смоделированы через встроенные `dict` и `list`).

### Список использованных источников

## 🚀 Руководство по запуску программы (КТ2)

Процедурная часть реализована на чистом **Python 3.12** без сторонних зависимостей (используется только стандартная библиотека).

### 1. Требования к окружению
* Установленный интерпретатор **Python версии 3.10+** (рекомендуется **3.12**).

Перейдите в директорию с исходным кодом и выполните запуск:
